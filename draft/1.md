@aromix/view Module Specification

1. Executive Summary & Architectural Overview @aromix/view is a server-driven,
   full-stack Single-Page Application (SPA) view engine designed for
   high-concurrency Node.js environments. It unifies Server-Side Rendering (SSR)
   for search engine optimization (SEO) and initial page loads with a
   persistent, low-latency WebSocket connection for subsequent SPA navigation
   and stateful business interactions.

The primary goal of @aromix/view is to eliminate the architectural overhead of
client-side virtual DOMs, REST/GraphQL endpoints, Data Transfer Objects (DTOs),
and manual client-side state synchronization. It uses a hybrid operational mode:

Initial Access (HTTP GET): Executes full component mounting and layout wrapping,
returning a fully rendered HTML document for instant First Contentful Paint
(FCP) and web indexing.

Subsequent Interactions & Navigation (WebSocket + layos): Routes events and
route transitions over a persistent WebSocket pipe, mutating isolated server
states and returning pre-compiled HTML fragments directly into the DOM via layos
tokens.

2. Fundamental Architectural Decisions 2.1. Separation of Concerns: Cosmetic vs.
Business State Cosmetic Client State: Handled entirely within the client DOM
using layos declarative attributes (e.g., toggling menus, open/close modals,
hover states). These do not trigger network traffic or WebSocket frames.

Business Domain State: Mutated and held exclusively on the server. Business
actions (e.g., database writes, state transitions, checkout flows) send events
to @aromix/view and receive updated HTML patches.

2.2. Decoupled Memory Model (Anti-Closure Protocol) To protect Node.js from
Garbage Collection (GC) pauses and process crashes, components never store state
inside persistent WebSocket closures. State is decoupled into a centralized L1
Session State Store (Map<SessionId, Map<ComponentId, State>>).

If a WebSocket drops and reconnects, the connection re-attaches to the existing
SessionId without data loss.

Inactive sessions are swept automatically via an internal Time-To-Live (TTL)
background process.

2.3. Pre-Compiled Static Chunk Array Templates To eliminate V8 heap churn caused
by continuous string concatenations, templates use a tagged template function
(html). During application initialization, static markup strings are parsed once
into an immutable array of chunks (WeakMap cache). At runtime, interpolation
simply splices values into the gaps between pre-cached static array indices.

2.4. Fault Isolation via @aromix/reactor All incoming WebSocket event handlers
execute inside an @aromix/reactor execution node. If an event handler throws an
unhandled error:

The error is safely caught within the reactor step boundary.

The failure is logged through @aromix/core (track).

An error payload is sent to the client component.

The WebSocket connection remains open and the global Node.js process does not
crash.

TypeScript const TEMPLATE_CACHE = new WeakMap<TemplateStringsArray, string[]>()

export interface CompiledTemplate { __isAromixTemplate: true chunks: string[]
values: any[] }

export function html(strings: TemplateStringsArray, ...values: any[]):
CompiledTemplate { let chunks = TEMPLATE_CACHE.get(strings)

if (!chunks) { chunks = Array.from(strings) TEMPLATE_CACHE.set(strings, chunks)
}

return { __isAromixTemplate: true, chunks, values } }

export function assembleTemplate(template: CompiledTemplate): string { const {
chunks, values } = template let result = '' const len = values.length

for (let i = 0; i < len; i++) { result += chunks[i] + (values[i] ?? '') } result
+= chunks[len]

return result } 4.2. Decoupled L1 Session State Store TypeScript export
interface SessionContainer { id: string lastActive: number states: Map<string,
Record<string, any>> }

export class SessionManager { private sessions = new Map<string,
SessionContainer>() private ttlMs: number

constructor(ttlMs = 1800000, sweepIntervalMs = 300000) { this.ttlMs = ttlMs
setInterval(() => this.sweep(), sweepIntervalMs).unref() }

get(sessionId: string, componentName: string): Record<string, any> | null {
const session = this.sessions.get(sessionId) if (!session) return null
session.lastActive = Date.now() return session.states.get(componentName) || null
}

set(sessionId: string, componentName: string, state: Record<string, any>): void
{ let session = this.sessions.get(sessionId) if (!session) { session = { id:
sessionId, lastActive: Date.now(), states: new Map() }
this.sessions.set(sessionId, session) } session.lastActive = Date.now()
session.states.set(componentName, state) }

private sweep(): void { const now = Date.now() for (const [id, session] of
this.sessions.entries()) { if (now - session.lastActive > this.ttlMs) {
this.sessions.delete(id) } } } } 4.3. Universal HTTP & WebSocket Dispatcher
Engine TypeScript import { node } from '@aromix/reactor'

export class ViewEngine { private config: any public sessionManager:
SessionManager

constructor(config: any) { this.config = config this.sessionManager = new
SessionManager( config.session?.ttlMs, config.session?.sweepIntervalMs ) }

// 1. HTTP Server-Side Rendering (SSR) Entrypoint async handleHttpRequest(req:
Request): Promise<Response> { const url = new URL(req.url) const route =
this.matchRoute(url.pathname)

    if (!route) {
      return new Response('404 Not Found', { status: 404 })
    }

    const sessionId = this.extractOrCreateSessionId(req)
    const params = this.extractParams(route.path, url.pathname)

    const initialState = await route.view.mount({
      params,
      sessionId,
      query: Object.fromEntries(url.searchParams)
    })

    this.sessionManager.set(sessionId, route.view.name, initialState)

    const compiledTemplate = route.view.render(initialState)
    const pageContentHtml = assembleTemplate(compiledTemplate)

    const fullDocumentHtml = this.config.layout({
      content: pageContentHtml,
      title: route.view.title ? route.view.title(initialState) : undefined
    })

    return new Response(fullDocumentHtml, {
      headers: {
        'Content-Type': 'text/html; charset=utf-8',
        'Set-Cookie': `aromix_sid=${sessionId}; Path=/; HttpOnly; SameSite=Lax`
      }
    })

}

// 2. WebSocket Protocol Router async handleSocketMessage(ws: any, rawData:
string): Promise<void> { try { const frame = JSON.parse(rawData) const { type,
sessionId, path, componentName, event, payload } = frame

      // SPA Navigation over WebSocket
      if (type === 'NAVIGATE') {
        const route = this.matchRoute(path)
        if (!route) return

        const params = this.extractParams(route.path, path)
        const initialState = await route.view.mount({ params, sessionId })

        this.sessionManager.set(sessionId, route.view.name, initialState)

        const compiledTemplate = route.view.render(initialState)
        const htmlOutput = assembleTemplate(compiledTemplate)

        ws.send(JSON.stringify({
          type: 'NAVIGATE_ACK',
          path,
          target: 'app-root',
          html: htmlOutput
        }))
        return
      }

      // Business Event Mutation over WebSocket
      if (type === 'EVENT') {
        const routeComponent = this.findComponentByName(componentName)
        const currentState = this.sessionManager.get(sessionId, componentName)

        // Execute in Reactor boundary for fault isolation
        const executionNode = node({
          name: `view-event:${componentName}:${event}`,
          async run() {
            const nextState = await routeComponent.events[event](currentState, payload, { sessionId })
            this.sessionManager.set(sessionId, componentName, nextState)

            const compiledTemplate = routeComponent.render(nextState)
            return assembleTemplate(compiledTemplate)
          }
        })

        const htmlOutput = await executionNode.run()

        ws.send(JSON.stringify({
          type: 'PATCH',
          target: 'app-root',
          html: htmlOutput
        }))
      }
    } catch (err) {
      // Process resilience boundary
      ws.send(JSON.stringify({
        type: 'ERROR',
        message: 'An internal error occurred.'
      }))
    }

}

private matchRoute(pathname: string) { return this.config.routes.find((r: any)
=> { const pattern = new RegExp('^' + r.path.replace(/:[^\s/]+/g, '([^/]+)') +
'$') return pattern.test(pathname) }) }

private extractParams(routePath: string, actualPath: string) { const keys:
string[] = [] const pattern = new RegExp('^' + routePath.replace(/:([^\s/]+)/g,
(_, key) => { keys.push(key) return '([^/]+)' }) + '$')

    const matches = actualPath.match(pattern)
    if (!matches) return {}

    return keys.reduce((acc, key, index) => {
      acc[key] = matches[index + 1]
      return acc
    }, {} as Record<string, string>)

}

private extractOrCreateSessionId(req: Request): string { const cookieHeader =
req.headers.get('cookie') || '' const match =
cookieHeader.match(/aromix_sid=([^;]+)/) return match ? match[1] :
`sess_${Math.random().toString(36).substring(2, 15)}` }

private findComponentByName(name: string) { const route =
this.config.routes.find((r: any) => r.view.name === name) return route ?
route.view : null } } 5. Client Integration Protocol (layos) The client

TypeScript // aromix-client.js class AromixClient { private socket: WebSocket

constructor(url: string) { this.socket = new WebSocket(url)
this.initSocketListeners() }

private initSocketListeners() { this.socket.onmessage = (event) => { const data
= JSON.parse(event.data)

      if (data.type === 'PATCH' || data.type === 'NAVIGATE_ACK') {
        const target = document.getElementById(data.target)
        if (target) {
          target.outerHTML = data.html
        }
      }
    }

}

public send(payload: object) { if (this.socket.readyState === WebSocket.OPEN) {
this.socket.send(JSON.stringify(payload)) } } }

complete, populated HTML document containing structured page data.

Memory Safety Verification: The WebSocket server maintains zero business state
in socket closures. All state resides in the L1 Session Manager, governed by TTL
auto-cleanup.

Garbage Collection (GC) Minimization: Component templates pre-split static
chunks into cached arrays at startup, keeping runtime heap allocations near
zero.

Fault Resilience: Component exceptions thrown during WS event processing are
contained by @aromix/reactor step boundaries, preventing process-level Node.js
crashes.
